# Contributing

Useful contributions include a reproducible example where the skill changes the task, lectures unnecessarily, loses quotation context, or behaves differently on equivalent neutral and profane prompts.

For behavioral reports, include the prompt, the complete response, model and version if known, date, whether the skill was enabled, and whether a fresh conversation was used. Remove private information before sharing. Describe observed behavior rather than assuming a hidden moderation decision.

Keep the skill small and instruction-only. Prefer contextual examples over lists of banned words. Changes should preserve meaning, handle ordinary frustration naturally, and retain the same treatment of the underlying request regardless of tone.

For a pull request, explain the concrete problem and compare the relevant paired prompts before and after the change. Update the evaluation notes only with checks actually performed. Do not claim Claude testing from reviews performed with a different assistant.
